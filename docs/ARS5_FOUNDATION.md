## Безопасная диагностика версий

Добавлена отдельная команда только для чтения:

```bash
python scripts/inspect_ml_environment.py --url https://test.autoxak.ru
```

Она выводит:
- ревизию и наличие изменений локального checkout с явной пометкой, что это не версия сервера;
- готовность/возраст heartbeat, тег и точный ID runtime из публичного ответа;
- при явно указанных контейнерах — только image ID, image reference и необязательный OCI revision label.

Не выводятся переменные окружения, ошибки с телами ответов, логи, модели, результаты и идентификаторы поездок. Не читаются .env, веса или БД. Нет загрузки пакетов, рестарта, сборки или развёртывания. Известные JSON-поля выбираются явно, весь Docker inspect не печатается.

В существующей серверной тестовой среде:

```bash
bash deploy/test_ml.sh versions
```

Команда определяет ID контейнеров через существующую test-конфигурацию и делает ограниченный Docker inspect. Отсутствующий revision label остаётся null; тег с коротким коммитом не считается доказательством полного SHA. Полный путь с Docker требует серверной проверки в ARS-6.

Exit code 0 означает свежий ready-heartbeat с корректным runtime image ID; это НЕ проверка инференса. Exit code 1 означает, что этот критерий не подтверждён. API/controller могут оставаться unknown без доступа к Docker; смотреть их отдельные статусы.

## Подготовка и проверки

Скрипты ARS-5 используют стандартную библиотеку Python и не требуют подключения БД/Redis или загрузки VED-весов.

```bash
python -m unittest discover -s tests/diagnostics -v
bash -n deploy/test_ml.sh
python scripts/preserve_ved_snapshot.py --verify /path/to/snapshot

```

Для ARS-6, отдельно в Linux/Docker-окружении:

```bash
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest --confcutdir=tests/ml tests/ml
docker build -f deploy/Dockerfile.ml-runtime -t autoxak-ml-runtime:qa .
docker build -f deploy/Dockerfile.ml-controller -t autoxak-ml-controller:qa .
AUTOXAK_ML_DOCKER_INTEGRATION=1 python -m pytest --confcutdir=tests/ml tests/ml
npm ci --prefix tests/browser
PYTHON_BIN=python node tests/browser/ml_workbench.cjs
```

Браузерные зависимости и фактический Chromium должны быть доступны в Linux-окружении. Эти Docker/браузерные команды здесь документированы, но не выполнялись в ARS-5. Не использовать обычный общий pytest без подготовки: корневой conftest запускает работу с БД.
