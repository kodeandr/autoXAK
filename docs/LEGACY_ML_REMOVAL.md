# Точечное удаление прежней обученной модели

Исходная ревизия: `9969ec0a2e65b37278bc46d9dddfbb804f6583f9` (`main`,
проверена 27 октября 2026). Старые признаки, веса, карточка и происхождение,
загрузчик и зависимость CatBoost удалены. Общий коммит ввода модели и API
записи не откатывается. Новый алгоритм и его зависимости выбираются после
нового эксперимента; новый документ о модели пока не создаётся.

Для новых записей через v1/raw_recording и v2/complete сохраняется статус
`model_not_trained`, а не нулевой прогноз. Отдельный исследовательский прогноз
не добавляется в math_status. Исторические записи и повторная отправка уже
завершённой поездки возвращают прежний сохранённый результат. Поле
trip_recordings.fuel_estimate остаётся nullable JSON; миграция не требуется.

Сохранены профили RecordingVehicle, сырые GPS/IMU, контрольные показания,
чанки, завершение, история, полный экспорт, авторизация, IndexedDB и очередь
браузера. Браузер отправляет целую поездку по v1; v2 остаётся отдельным API.
Математическое ядро reference_math и его контракты не изменяются.

Хеш коммита удаления фиксируется отдельно в PR и отчёте о выполнении.
В checkout с этой историей его можно получить командой:

```bash
git log -1 --format=%H --diff-filter=A -- docs/LEGACY_ML_REMOVAL.md
```

Для воспроизводимости следующего исследования сохраняйте этот хеш вместе
с версией данных, правилами разбиения и контрольными измерениями. Удалённые
артефакты остаются в предыдущей истории Git, но не входят в текущий образ.

Проверки: установка requirements.txt в чистом venv без CatBoost, запуск API,
v1/v2 с null-прогнозом, полный экспорт обеих сенсорных последовательностей,
показания после поездки, идемпотентность, старые завершённые результаты и
неизменённые аналитические тесты математического ядра.
