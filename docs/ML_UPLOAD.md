# Файлы будущих моделей на test.autoxak.ru

Страница `https://test.autoxak.ru/ml` и API `/api/v3/ml/models` доступны
без аккаунта, пароля и выдачи персональных прав, если одновременно заданы
`APP_ENV=test` и `ML_UPLOAD_ENABLED=true`. Любой посетитель может загружать
и удалять комплекты. В production эти переменные не добавляются.

Старая обученная модель удалена отдельным откатом:
[LEGACY_ML_REMOVAL.md](LEGACY_ML_REMOVAL.md). Этот раздел служит хранилищем
для нового эксперимента. Веса не интерпретируются, библиотеки алгоритмов
не загружаются, кнопки активации нет. Прогноз расхода остаётся недоступным:
`model_not_trained`, литры — `null`. Новый формат инференса, зависимости
и его документ выбираются после сравнения алгоритмов.

## Работа с файлами

Укажите название и описание, выберите от 1 до 16 файлов и нажмите «Загрузить».
До 20 МиБ на комплект, 10 комплектов и 100 МиБ всего. Имена файлов: латинские
буквы, цифры, точки, дефисы и подчёркивания, до 120 символов. ZIP можно
сохранить как один файл; сервер его не распаковывает. Пустые файлы не принимаются.

Сервер сохраняет исходные байты и вычисляет SHA-256 каждого файла. Он проверяет
размер и транспортную целостность, но не подтверждает качество или совместимость
алгоритма. Для удаления нажмите «Удалить» у нужного комплекта. Загрузка/удаление
не меняют поездки, контрольные измерения, расчётное ядро или историю.

Реестр и файлы остаются в томе `autoxak-test_ml` после пересоздания API.
Если ранняя версия загрузчика уже использовалась, прежние комплекты остаются
обычными файлами. Старая ссылка active игнорируется и не включает инференс.
Комплекты старого формата тоже можно удалить, не устанавливая CatBoost.

## Обновление существующей тестовой среды

Предпосылки: существующие `/opt/autoxak-test/.env.test` и `compose.test.yml`,
проект `autoxak-test`, порт 8001 и его PostgreSQL/Redis. Сначала примените
точечный откат, затем обновлённый загрузчик; draft загрузчика основан на откате.
Новый staging-стек не нужен и конфликтовал бы с уже занятой подсетью.

При первой установке:

```bash
git clone --branch feat/public-test-model-manager https://github.com/kodeandr/autoXAK.git /opt/autoxak-ml-source
bash /opt/autoxak-ml-source/deploy/test_ml.sh start
bash /opt/autoxak-ml-source/deploy/test_ml.sh check
```

Если checkout уже существует, обновите именно его ветку:

```bash
git -C /opt/autoxak-ml-source pull --ff-only
bash /opt/autoxak-ml-source/deploy/test_ml.sh start
```

Скрипт собирает отдельный autoxak-test-api, сохраняет проверяемый дамп
тестовой БД, затем пересоздаёт только тестовый API. Ошибка сборки/дампа
останавливает обновление. Production, PostgreSQL и Redis не перезапускаются.
Прежние база, порт, сети и секреты берутся из compose.test.yml; для файлов
добавляется отдельный том. Каталог подготовлен для UID 10001, остальная
файловая система контейнера остаётся read-only.

Управление после установки выполняется постоянным скриптом, а не временной
функцией tdc или одним старым Compose-файлом:

```bash
bash /opt/autoxak-ml-source/deploy/test_ml.sh status
bash /opt/autoxak-ml-source/deploy/test_ml.sh logs
curl --fail http://127.0.0.1:8001/ready
curl --fail https://test.autoxak.ru/api/v3/ml/models
```

HTTPS и Nginx остаются прежними. Нужен client_max_body_size не менее 28m
для JSON/base64; в конфигурации из чата уже 150m. Браузерные изменения
принимаются с того же origin; прямой API намеренно анонимный, с заголовком
`X-Model-Manager: 1`. Если ранее добавлен общий Nginx gate, для прямого
доступа должны быть доступны /ml, /api/v3/ml/ и /static/ml.* без этого gate.

Резервируйте том отдельно от PostgreSQL. Для согласованной файловой копии
остановите только тестовый API, скопируйте autoxak-test_ml и снова запустите
API с той же Compose-надстройкой. При обновлении том не удаляется.

## Проверки

```bash
python -m pytest --confcutdir=tests/ml tests/ml
PYTHON_BIN=python node tests/browser/ml.cjs
```

Проверяются анонимный доступ, отсутствие активации и зависимостей модели,
загрузка исходных байтов, хеши, восстановление реестра, удаление, старый
формат хранилища, ограничения, ошибки записи, пути файлов и доступ с другого
origin. Браузерная проверка выполняется без установленного CatBoost.
