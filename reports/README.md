# Происхождение отчётов

Файлы этого каталога, созданные до математического ядра 2.0, являются
историческими отчётами. Они не загружаются ядром и не удостоверяют точность
текущей версии. Реальные парные контрольные логи владельцем пока не предоставлены.

Автоматические утверждения о H1/эталонном износе масла из прежних синтетических
формул использовать как доказательство нельзя. Формат новых явно маркированных
проверок и ограничения описаны в [REFERENCE_MATH.md](../docs/REFERENCE_MATH.md).
