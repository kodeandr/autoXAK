# Запись демо autoXAK без автомобиля

Инструмент запускает отдельный Chromium с чистой гостевой сессией и записывает видео обычного приложения. Подаёт синтетические GPS и DeviceMotionEvent, но не подменяет ответы API, расчёты, деньги или значения счётчиков в интерфейсе.

## Windows: запуск

1. Установите Node.js 22 или новее с https://nodejs.org и заново откройте PowerShell.
2. Распакуйте `autoxak-demo.zip` в отдельную папку. Файлы приложения заменять не нужно.
3. Откройте PowerShell в распакованной папке `autoxak-demo`.
4. Для локально работающего приложения:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Record-Demo.ps1 -Url "http://localhost:8000"
```

Для обычного приложения на сервере явно укажите его адрес:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Record-Demo.ps1 -Url "https://autoxak.ru"
```

`-Url` — корень приложения без `/ml`, `/history` и других путей. Приложение и PostgreSQL должны работать; каталог должен содержать `haval_jolion_15t_4wd`. Городской расход в новом гостевом профиле выбирается через обычный интерфейс: 8,5 л/100 км.

Скрипт устанавливает свои npm-зависимости и Chromium в стандартный пользовательский кэш Playwright, открывает окно и примерно за полторы минуты записывает сценарий. Не закрывайте это окно. Наличие видимого окна не обязательно: добавьте `-Headless`, если хотите записать видео без окна.

## Короткое видео: 20 секунд, поездка 10–15 км

В архиве есть `sample-video-20s.mp4` и `sample-report-20s.json` — готовый короткий пример и результат его проверки.

Для повторной записи установите FFmpeg (`winget install --id Gyan.FFmpeg -e`), откройте новый PowerShell и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Record-Demo.ps1 -Url "https://autoxak.ru" -Short
```

В режиме `-Short` рассчитывается отдельная синтетическая поездка длительностью 20 минут и дистанцией 10–15 км. Все 60 001 отсчёт IMU и 1 201 точка GPS проходят через обычный frontend и backend. Скорость, координаты и ускорение согласованы; дистанция и рубли не подставляются. Сценарий воспроизводится с ускоренной подачей синтетического времени. Затем FFmpeg вырезает середину записи, оставляя главную, старт, конец поездки, свайп, итоги, копилку и историю. На видео постоянно обозначен демонстрационный характер. Это не запись 20 минут реального движения.

Результат: `output/<время>/demo-20s.mp4`, исходное видео, полный экспорт и `report.json`. Длина итогового клипа — 20 секунд. Рубли рассчитываются по всем точкам полной поездки. Обычный режим без `-Short` по-прежнему записывает минутную синтетическую поездку.

Для Linux/macOS:

```bash
node record-demo.cjs --url http://localhost:8000 --headless --short
```

## Какая версия приложения нужна

Нужна обычная версия приложения с исправлениями продуктовых эпиков: `static/index.html` содержит `sum-smooth`, а backend рассчитывает рубли через TwinEngine. Проверено на рабочей копии `776a718bba4c56578ecbfa37c67c3f110e8cad99` с этими исправлениями и импортом каталога.

На `test.autoxak.ru` в предыдущем серверном отчёте развёрнут `93a61f6ffcb9` — отдельная ML-ветка, которая предшествует этим исправлениям. Для записи полной обычной поездки с рублями этот вариант не подходит. Скрипт проверяет интерфейс до создания гостя и выдаёт ошибку, если версия несовместима. Сценарий `/ml` этим инструментом не записывается.

## Что будет в видео

- Вход новым гостем, выбор Haval Jolion через гараж.
- Начало поездки с GPS 1 Гц и IMU 50 Гц.
- 60 секунд по заданному профилю: калибровка на месте, плавный разгон, резкий разгон, резкое торможение, две неровности при движении и остановка.
- Завершение поездки настоящими Pointer Events свайпа.
- Итоги от реального backend, кнопка копилки, обновлённая главная.
- История, перезагрузка страницы и подробности сохранённой поездки.

Рубли вычисляются сервером по фактическому синтетическому массиву; фиксированной суммы в сценарии нет. На видео постоянно видна подпись «ДЕМО · синтетическая поездка». Это проверка программного сценария, не доказательство дорожной точности датчиков или расхода.

## Данные и изоляция

Каждый запуск создаёт нового гостя и одну настоящую запись поездки в БД выбранного адреса. Существующие аккаунты и браузерные профили не используются. На production это всё равно дополнительные демонстрационные данные: для полной изоляции используйте локальную или отдельную тестовую копию обычного приложения. Созданные данные автоматически не удаляются.

Синтетические координаты начинаются в Москве. Записей реальных поездок и персональных данных в инструменте нет. Экспорт содержит только данные созданной поездки; пароли и токены в отчёт не записываются.

## Результат

Файлы находятся в `output/<время-запуска>/`:

- `demo.webm` — видео без микрофона и звука, открывается Chrome/Edge/VLC.
- `demo.mp4` — создаётся дополнительно, если в PATH установлен FFmpeg с libx264; этот формат удобен для PowerPoint.
- `report.json` — результат проверок, реальные показания backend и подтверждение сохранения.
- `telemetry.synthetic.json` — полный экспорт синтетической поездки.
- `active-trip.png`, `trip-summary.png`, `history.png` — настоящие снимки интерфейса.

Если прогон прервался, сохраняются `partial-failed.webm`, `failure.png` при доступной странице и `report.json` со статусом `failed`. Ошибка не маскируется под успешное демо. Проверьте, что backend, каталог и нужная версия интерфейса доступны. Если ошибка произошла после создания гостя или поездки, эти данные могут остаться на выбранном сервере.

Для MP4 при отсутствии FFmpeg установите его, откройте новый PowerShell и преобразуйте полученное видео:

```powershell
winget install --id Gyan.FFmpeg -e
```

Затем из папки конкретного результата:

```powershell
ffmpeg -i .\demo.webm -c:v libx264 -pix_fmt yuv420p -movflags +faststart .\demo.mp4
```

В видео можно добавить собственный голос и подписи в редакторе. Математика приложения и дизайн файлов проекта этим инструментом не изменяются.

## Linux / macOS

```bash
npm ci
npx playwright install chromium
node record-demo.cjs --url http://localhost:8000
```

На Linux могут потребоваться системные зависимости Chromium. В облачной проверке использован установленный Chromium через `CHROMIUM_PATH=/usr/bin/chromium` и системный FFmpeg; PowerShell-обёртка на Windows в этой среде не исполнялась.
