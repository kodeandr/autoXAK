# autoXAK: скриншоты без верхней подписи

Четыре PNG-изображения, 852 × 1846 пикселей. Из версий скриншотов удалена верхняя строка «ДЕМО · синтетическая поездка · середина вырезана». Файлы обработаны редактором изображений; исходные снимки браузера доступны в соседнем комплекте `autoxak-demo-screenshots`.

- `01-trip-history.png` — история, копилка и график.
- `02-active-trip.png` — статистика активной поездки.
- `03-trip-report.png` — итоговый отчёт.
- `04-history-list.png` — список последних поездок.

Данные остаются синтетическими, как в демо-видео. Показатели проверены по исходным изображениям: новая поездка +50,72 ₽, 13 км, 20 минут, 3 резких старта, 4 торможения, 7 неровностей, индекс 97/100; после поездки — 60 поездок и 1 826,20 ₽ в копилке. Средний индекс за 7 дней — 89,9, изменение +4,3 пункта.

В `manifest.json` указаны контрольные суммы оригиналов и обработанных файлов. Изменения кода приложения и базы данных не выполнялись.
