# Воспроизводимый первый эксперимент VED

Здесь сохранены обучение и компактные результаты от 18 октября 2026. Это исходный
эксперимент на скорости автомобиля; актуальная обработка смартфонного GPS находится
в `app/services/fuel_prediction.py`, веса — `app/ml/artifacts/`.

В папке `reports/` лежат аудит, разбиение машин, метрики и график. Сырые данные VED,
полные предсказания и окружение в Git не включены. `run_manifest.json` — исторический
манифест локального эксперимента; текущие SHA256 весов находятся в `app/ml/artifacts/provenance.json`.

Создать отдельное окружение Python 3.12 и выполнять из этой папки:

```sh
python -m venv .venv
# Windows: .venv/Scripts/python.exe; Linux/macOS: .venv/bin/python
python -m pip install -r requirements.txt
python bootstrap_data.py --download --extract
python -m unittest test_pipeline.py
python prepare_dataset.py
python train_models.py
```

После создания окружения команды `python` должны относиться именно к нему.
Два архива VED и таблица характеристик загружаются из репозитория авторов и проверяются
по зафиксированным Git blob-хешам. После распаковки требуется несколько ГБ диска.
Обучение сохраняет новые веса в `research/models/`; оно **не заменяет автоматически**
модель приложения. Для замены нужны независимая проверка, обновление model_card,
provenance и новая версия модели.

В этом снимке 232 932 участка, 184 машины. Test/validation/train разделены по машинам.
Контрольный расход восстановлен по MAF: это оценка, а не независимое измерение заправкой.
Тестовая WAPE по записанным фрагментам: физика 11,60%, гибрид 10,55%, прямой CatBoost 9,61%.
Эти цифры не характеризуют точность на GPS смартфона, Audi или виртуальных поездках.

Источник: [VED](https://github.com/gsoh/VED), [статья авторов](https://arxiv.org/abs/1905.02081).
Параметры подготовки и единицы указаны в `reports/first_experiment.md`.
